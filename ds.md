# Data Structures

> Part of the **Tech Track** bootcamp — *Coding Interview: Algorithms and Data Structures*.
> Companion track: [Algorithms](alg.md)

## Overview

In this track you will learn data structures by solving practice problems. You begin
by learning to solve well-defined problems related to a particular data structure.
By the end of the track you will be able to evaluate and assess different data
structures for any open-ended problem, and implement a solution based on your
design choices.

Choosing a data structure is choosing a set of trade-offs. Every structure makes some
operations cheap and others expensive; the work of this track is learning to read
those trade-offs and to pick the structure that makes the *dominant* operation of
your problem the cheap one.

## Objectives

This track is primarily designed to boost your knowledge in data structures by
closing technical preparation gaps. It is mainly aimed at current software engineers
with some years of experience.

## Learning Outcomes

By the end of this track you will be able to:

- Evaluate the complexity and quality of the data structures proposed for a
  given problem.
- Study the most representative, introductory data structures used across the
  most important classes of problems treated in computation.
- Solve problems by selecting and composing the fundamental data structures.
- Answer the following questions when a new data structure is presented:
  - What are the costs of its core operations?
  - Is there a structure that solves this problem more cheaply?

## Prerequisites

An understanding of logic, mathematics, and algorithms is assumed, along with
proficiency in at least one programming language.

## Course Outline

The data structures track is organized into two units, added in the layers that follow:

| Unit | Topic |
|---|---|
| 03 | List Data Structures |
| 04 | Multi-way Data Structures |

Units 01, 02, 05 and 06 cover algorithms and live in [alg.md](alg.md).

## Session Format

Each unit is delivered through three session types:

- **reading** — pre-work, done before the session.
- **seminar** — guided, worked through together.
- **homework** — self-paced, completed after the session.
